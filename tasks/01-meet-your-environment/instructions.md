# Meet your environment

Welcome! The terminal on the right is a real Linux environment that belongs to you for
this workshop. Everything you create in `/workspace` is saved — you can stop the
environment, come back tomorrow, and your files will still be here.

## 1 · Look around

Run a couple of commands to get your bearings:

```bash
pwd
```

```bash
ls -la
```

You're in `/workspace` — your project directory for the whole workshop.

## 2 · Create your first file

Create a file called `hello.txt` containing your name:

```bash
echo "Your Name" > hello.txt
```

:::tip[The terminal survives everything]
Reload this page — the terminal comes back exactly where you left it, scrollback and
all. Your session lives in the environment, not in your browser tab.
:::

When the file is in place, press **Check task** below the instructions.
